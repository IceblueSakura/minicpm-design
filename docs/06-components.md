# 组件清单

组件分三类。这张表回答一个问题：这个东西到了原生端，是用系统控件，还是自己画。

- **系统**：用平台控件，只传语义和文案。
- **组合**：用系统控件拼成固定结构，结构要跨端一致。
- **自绘**：平台没有对应物，要自己实现，是产品辨识度所在。

各平台具体控件见 [平台落地](07-platforms.md)。

## 自绘

### 双轨波形

实时会话的标志。规格见 [设计语言](02-design-language.md#双轨波形)。

| 属性 | 规格 |
|---|---|
| 输入 | 你的电平、模型的电平，每秒 12 个采样 |
| 布局 | 共用横轴，上轨你，下轨模型，最新在右 |
| 重叠 | 两轨同时超过阈值时，整列铺 `overlap` |
| 刻度 | 每秒一个点，模型说话时用模型色 |
| 帧标记 | 模型取了一帧画面时，上沿一个短刻度 |
| 暂停 | 停止滚动，透明度 45% |
| 减弱动态效果 | 每 0.5 秒更新一次 |
| 读屏 | 整体一个图片角色，不朗读采样 |

### 实时控制条

实时会话时替换输入框。

| 区域 | 内容 |
|---|---|
| 状态 | 状态灯、当前状态词、采集点、时长、运行情况。点开看运行状态和主动提醒 |
| 波形 | 双轨波形 |
| 控制 | 麦克风、画面、定格提问、先听我说、转文字、结束 |
| 提示槽 | 暂停、重连、即将自动暂停时出现，一次只显示一条 |

紧凑形态把定格提问和转文字收进“更多”，波形变矮，控制占满一行。暂停时控制换成继续、转文字、结束。

结束按钮永远在最后，永远可点，任何状态下都不隐藏。

### 实时取景

| 属性 | 规格 |
|---|---|
| 边框 | 采集中 2px 朱砂框。不采集时变成细线 |
| 取帧 | 模型取一帧时四角亮一下 |
| 标签 | 左上写处理位置和频率，右上是来源或翻转摄像头 |
| 暂停层 | 模糊画面，写明原因和“看不到”的事实 |

紧凑形态全屏，转写收进底部面板，最新一句显示为字幕。

### 远看模式

语音实时放远看的画面。规格见 [实时会话](04-live-session.md#远看模式)。复用实时取景的朱砂框和标签，中间是放大的状态灯和状态词，点屏幕退出。

### 话轮记录

实时转写的一段话：左侧竖线（模型为青瓷）、说话人、标记（主动提醒、被你打断、已让它停下、说到一半暂停）、文字。

系统造成的中断用**空白标记**：居中小字，两侧细线。

结束后整段折叠成一行：来源、时长、缩略时间线。

### 品牌标记

图形是双轨波形的静态版本：上方五根墨色短线，下方五根青瓷色短线。用于应用图标、欢迎页、新对话、锁定页。

## 组合

| 组件 | 结构 | 说明 |
|---|---|---|
| 输入框 | 添加、文字、语音消息、实时/发送 | 紧凑形态是圆角胶囊，内容增多时长高 |
| 用户消息 | 右对齐气泡，附件在气泡上方 | 系统气泡样式不适用，自己定义但用系统字体 |
| 模型回答 | 无气泡，全宽正文 | 工具行：复制、重新生成、朗读。紧凑形态只在最后一条显示，其他长按 |
| 步骤与思考 | 可折叠的一行 | 默认折叠 |
| 语音条 | 播放按钮、音条、时长 | 语音回复 |
| 附件 | 缩略图、名称、大小、移除 | 不支持时标红 |
| 产物卡片 | 图标、名称、大小、打开 | 打开走系统预览 |
| 代码块 | 语言、复制、等宽内容 | 块内横向滚动 |
| 联网询问 | 问题、说明、发送内容、两个按钮 | 决定前不发送 |
| 联网记录行 | 图标、发送内容、跳转 | 留在对话里 |
| 系统动作卡 | 问题、说明、时间和内容、两个按钮 | 定时通知和备忘录。决定前什么都不发生，结果留一行记录 |
| 记忆行 | 图标、已记住的内容、撤销、管理 | 留在对话或转写里。删除后不再显示原文 |
| 规格选择 | 词、小字精度、说明、大小 | 单选。内存不够时不可选并写原因。用系统分段控件或列表 |
| 来源标记 | 回答里的数字带虚线下划线 | 点开对照原图。看不清时旁边有标记 |
| 对照原图 | 原图局部和高亮、读到的原文、位置、动作 | 用系统面板。动作是看完整原图和这里读错了 |
| 状态横幅 | 图标、一句话、动作 | 输入框上方，一次一条。优先级见下 |
| 提示卡 | 图标、标题、说明、动作 | 在对话流里，比如对话快满 |
| 建议 | 图标、标题、说明 | 紧凑形态是横向滚动的胶囊 |
| 下载进度 | 进度条、状态文字、动作 | 欢迎流程、横幅、模型设置共用 |
| 权限说明 | 图标、用途、处理位置、继续和现在不用 | 系统弹窗之前 |
| 实时状态条 | 状态、对话名、时长、返回、结束 | 用户离开实时所在的页面时出现 |
| 隐私声明 | 盾牌图标和一句话 | 新对话、设置、对话详情 |
| 设置项 | 名称、说明、控件 | 用系统列表 |
| 资源状态 | 模型名、状态、负载 | 仅展开形态的侧栏底部 |

**横幅优先级**：权限错误 > 远程未配置 > 离线模式挡住远程 > 浏览器跑不了 > 连不上 > 模型未下载或下载中 > 载不下 > 载入时退出 > 正在准备 > 换模型中 > 其他对话的实时占用 > 上次实时意外结束 > 发送崩溃报告。一次只显示最高的一条。

## 系统

这些在原生端一律用平台控件：导航栏、标题栏、侧栏、列表、开关、滑块、选择器、分段控件、按钮、文本框、搜索框、菜单、弹出菜单、底部面板、确认框、提示、进度指示、分享、文件和相册选择、权限弹窗、生物识别、音频输出选择、通知。

原型里这些控件的样式是网页端的最终样式，不是原生端的参考。比如原型的底部面板、开关、下拉框，到 iOS 和 Android 上都换成系统版本。
