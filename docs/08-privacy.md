# 隐私设计

隐私是这个产品的主要卖点，所以它是一套界面行为，不是一个设置页。

## 三个承诺

欢迎页的三句话是产品对用户的约定，所有设计都不能违反：

1. **内容不离开这台设备。** 声音、画面和文件都在本机处理。
2. **断网也能用。** 模型下载好之后不需要网络。
3. **都由你决定。** 记住了什么、联网做了什么，都能看到和删除。

连接远程服务时第一条不成立。这时所有声明都要改成写明发送到哪里，见下文。

Web 上模型跑在浏览器里，第一条同样成立。第二条要求页面能离线打开，见 [平台落地](07-platforms.md#web-特有)。浏览器扩展能读页面内容，这不在应用的控制范围内 **[推断]**，要写进隐私说明。

## 信号

用户任何时候都能回答这三个问题。

| 问题 | 信号 | 位置 |
|---|---|---|
| 内容在哪里处理？ | 本机处理 / 内容会发送到 example.com | 新对话、紧凑标题、取景标签、对话详情第一项、设置 |
| 现在有没有在听、在看？ | 状态灯、状态词、朱砂框、“模型看不到画面”、“没有在听” | 控制条、取景 |
| 有什么离开过设备？ | 联网记录 | 设置，对话里的记录行 |

系统自己的信号是兜底：iOS 橙点和绿点，Android 隐私指示器，macOS 菜单栏的点。应用内信号不替代它们，也不和它们矛盾。

## 规则

### 采集

- 采集开始前用户一定有明确动作。
- 系统造成的停止和闲置超时之后，恢复要用户点击。详见 [实时会话](04-live-session.md#打断暂停)。
- 画面默认不保存，转写默认保存，都可以改。
- 耳机断开时暂停，防止回答被外放。
- 长时间没说话自动暂停，防止忘记关闭。
- 手机上实时中暂停通知，避免通知内容被画面或录屏带走。

### 权限

- 用到时才问，问之前说明用途和处理位置。
- 被拒绝时给出路径，同时给替代方案：“在系统设置里允许后重试，或者先用文字继续”。
- 设置页列出每项权限的状态，管理按钮跳到系统设置。

### 联网

默认只有三类请求，都不含用户内容：检查更新（只发送版本号）、模型下载、用户同意的崩溃报告。

用户内容离开设备只有两种情况：

| 情况 | 控制 |
|---|---|
| 联网搜索 | 默认每次询问。卡片写明要发送的那句话，点了才发 |
| 远程服务 | 用户自己配置，全程写明发送到哪里 |

离线模式关闭全部联网，包括更新。

**联网搜索只发送搜索词。** 对话内容、文件、声音和画面都不发。搜索词由模型生成，可能带上用户的信息，所以要展示给用户确认。“自动”档存在这个风险，默认不开，选择时要提示。

**联网记录**列出最近 7 天的所有请求。有内容离开时，顶部的声明也要改，不能继续写“没有内容离开”。

### 记录与记忆

| 内容 | 默认 | 控制 |
|---|---|---|
| 对话记录 | 保存 | 可关闭，可自动清理（7、30、90 天） |
| 实时转写 | 保存 | 可关闭 |
| 实时画面 | 不保存 | 可开启 |
| 定格画面 | 作为附件保存 | 可模糊人脸 |
| 记忆 | 开启 | 可关闭，逐条查看和删除 |
| 临时对话 | 不保存，不写记忆 | 对话内开关，可设为默认 |

对“健康”“证件”这类敏感信息写入记忆前要不要询问，是待定问题。原型示例里有“你对青霉素过敏”，它有价值，也敏感。

### 访问

| 项目 | 说明 |
|---|---|
| 打开时验证 | 面容、指纹或系统密码。锁定页只有标记和解锁按钮 |
| 自动锁定 | 立即、1 分钟、5 分钟、不锁定 |
| 后台遮盖 | 最近使用的应用里只显示品牌标记 |
| 录屏和截屏 | Android 可以禁止。iOS 没有公开方法，录屏时遮盖内容 |
| 加密保存 | 用设备密钥 |

### 通知

通知内容在锁屏上可见，所以默认不写对话内容。

| 通知 | 文案 |
|---|---|
| 定时任务完成 | 每日汇总已经准备好 |
| 下载完成 | MiniCPM-o 4.5 准备好了 |
| 暂停的实时会话 | 实时会话已暂停 |

用户可以在系统设置里选择显示预览。

### 删除

- 单条对话和记忆可撤销，7 秒内。
- 清除全部不可撤销，这是少数需要确认的操作，写清范围。
- 临时对话清除没有撤销。
- 卸载应用等于删除全部，模型文件也一起删除。

## 远程服务

远程是次要路径，但一旦开启，文案必须如实变化。

| 位置 | 本机 | 远程 |
|---|---|---|
| 新对话 | 只在这台设备上处理，内容不会离开 | 内容会发送到 example.com 处理 |
| 取景标签 | 本机处理 · 每秒看 1 帧 | 正在上传 · 每秒看 1 帧 |
| 紧凑标题 | 本机 | 远程 |
| 开始实时 | 无额外提示 | 提示声音和画面会发送到哪里 |
| 对话详情 | 这台设备 | 服务器地址 |
| 设置 | 你的内容留在这台设备上 | 内容正发送到 example.com |
| 切换后的对话 | 从这里开始只在这台设备上处理 | 从这里开始发送到 example.com 处理，上文也包括在内 |

切换运行位置的规则：

- 切到远程时，这个对话的上文会随下一条消息发送，切换提示要写明，并提供撤销。
- 对话里的标记不能删除，让用户事后能看出哪部分离开过设备。
- 失败时绝不自动换运行位置，尤其不能自动转到远程。

访问令牌只进系统安全存储，界面只显示“已保存”。

## 应用商店披露

| 平台 | 需要准备 |
|---|---|
| iOS | `NSMicrophoneUsageDescription`、`NSCameraUsageDescription`，隐私营养标签，审核指南 2.5.14 要求录制有同意和明确提示 |
| Android | Data safety 表单，前台服务类型声明 |

用途说明文案和应用内权限说明保持一致。
